# DARS: Dependency-Aware Reward Shaping

Official codebase for **"Dependency-Aware Reward Shaping for Agentic Reinforcement Learning"**.

**Ziyi Chen\*, Yan Zhang\*, Jianhui Wei\*, Daoan Zhang, Zuozhu Liu**  
\* Equal contribution.

DARS assigns step-level credit through a dependency graph, using prerequisite relationships to shape rewards for agentic reinforcement learning.
